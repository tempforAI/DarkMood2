# DARK MOOD Ⅱ：雪葬村审判

一款在浏览器中运行的**本格推理审判冒险游戏**（原创作品），《DARK MOOD：宵鸦岛审判》（[tempforAI/DarkMood](https://github.com/tempforAI/DarkMood)）的续作。
没玩过第一部也可以直接游玩。

> 2003 年 2 月，东北深山。
> 承认过自己「少年时代的推理是错的」的侦探七濑律，和助手乌丸小夜，收到一封信：
> 「二十年前的冬天，我的母亲被村子『送进了雪里』。」
> 大雪封山、吊桥被切断。防灾广播里传来戴白蛾面具的「白蛾」的声音——依照古法，雪封之日，由村子自己审判。
> 投错了票，被裁定的人就会在黎明，被送进暴风雪。

## 怎么玩

不需要安装，不需要服务器：**直接用浏览器打开 `index.html`** 即可（Chrome / Edge / Firefox / Safari，电脑、手机、平板都可以）。
也可以用任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

| 操作 | 电脑 | 手机 / 平板 |
|---|---|---|
| 推进对话 | 点击 / 空格 / 回车 / Z | 点击画面 |
| 快进 / 自动 | 按住 Ctrl / A | 点「快进」「自动」 |
| 对话记录 | L | 点「记录」 |
| 菜单（存档/读档/手账/设置） | Esc 或右键 | 点「菜单」 |
| 寄合·证言交锋 | 数字键选证据，←→ 切换发言，点橙色字句 | 点选证据，再点橙色字句 |

手机竖屏时会提示横过来；标题画面左下角可进入全屏。存档默认保存在浏览器本地：9 个存档位 + 自动存档 + 分歧点存档；也可以指定云盘或外置硬盘上的文件夹（见下文）。

## 体量与结构

| 部分 | 内容 |
|---|---|
| 序章「雪葬之村」 | 登村、白蛾的广播、教学寄合 |
| 第一章「水车之雪」 | 冻住的水车，在深夜里开始捣米 |
| 第二章「无迹之雪」 | 雪地上没有凶手的脚印 |
| 第三章「汤烟之雪」 | 热汤里的尸体，和一个不会说话的证人 |
| 第四章「假面之雪」 | 侦探被关进雪牢——这一次，由助手主导审判 |
| 终章「雪葬审判」 | 白蛾的真面目，与二十年前那一夜 |

每章之后有一段幕间「雪之间」。约 1.4 万行剧本、31 个自由时间事件、60 余个推理小游戏。完整通关约 10～14 小时。

* 全部为**本格推理**：解开真相所需的每一条线索都会在寄合前呈现给玩家。
* 寄合中的推理小游戏**没有失败**——答错只扣「信念」并逐步给出提示。

## 结局

共 **7 个结局**：5 个坏结局、1 个好结局、1 个真结局。
关键时刻的**选择**，以及是否找到**可选证据**，会决定黎明时谁被送进雪里。
坏结局之后可以「回到分歧点」重新选择；标题画面的「结局一览」记录已达成的结局，并给出未达成结局的提示。
真结局需要和某些人物度过足够多的自由时间，并找到一件可选证据。

## 存档位置（换电脑继续玩）

设置 → 存档：

* **存档文件夹**（电脑版 Chrome / Edge）：点「选择文件夹…」，选 OneDrive、Dropbox 等云盘里的文件夹，或外置硬盘上的文件夹。
  之后的所有存档、自动存档、分歧点存档和结局记录都会自动写进其中的本作子文件夹，并与浏览器本地存档双向同步（同一存档位以较新的为准）。
  在另一台电脑上用 Chrome / Edge 打开游戏、选择同一个文件夹，就能继续玩；切回游戏窗口时会自动重新同步。
  浏览器重启后若要求授权，在标题画面右上角点「连接存档文件夹」即可。两部作品可以选同一个文件夹，各用各的子文件夹。
* **存档文件**（所有浏览器，包括手机）：「导出存档文件」下载一个 `.dmsave` 文件，放进云盘；在另一台设备上「导入存档文件…」。
* 画质设置与设备有关，不会同步。

## 画质设置（设置 → 画面）

| 项目 | 选项 |
|---|---|
| 画质预设 | 低（老设备/省电）/ 中 / 高 / 极高 / 自定义；首次启动按设备自动推荐 |
| 分辨率 | 自动 / 540p / 720p / 1080p / 2K / 4K |
| 模型精度 / 材质质量 / 光影质量 | 低·中·高 / 低·中·高 / 关·简单·完整 |
| 后期效果 | 关 / 暗角 / 电影感（泛光、胶片颗粒） |
| 角色环境光 | 立绘受场景光照（雪夜偏冷、炉火偏暖）并带轮廓光 |
| 天气粒子、帧率上限 | 少/中/多（雪、暴风雪）、30/60 |

## 技术说明

* 纯原生 JavaScript + Canvas 2D，无框架、无构建步骤、无任何外部图片或音频。
* **所有画面都由代码实时生成**：背景、立绘、小人、图标、地图在 1920×1080 设计坐标中矢量绘制，按输出分辨率与画质参数生成并缓存；
  **所有音乐与音效都由 Web Audio 实时合成**。
* 引擎与第一部完全共用，作品差异集中在 `js/data/game.js`。
* 兼容：ES5 语法 + 基础 Canvas 2D，不依赖 WebGL；「低」预设在老手机上也流畅。

```
index.html            入口
js/engine/            引擎（与第一部相同）
js/hd/                高清矢量美术：kit.js 工具包、chars.js 角色生成器、cast.js 角色配置、bg_*.js 背景、icons.js 图标
js/data/              game.js 本作配置；characters.js、locations.js、endings.js；chapters/ 各章剧本；freetime.js 自由时间
docs/OUTLINE.md       总纲（含剧透！）
docs/STORY_BIBLE.md   剧情圣经（全部真相与诡计设计——含剧透！）
docs/INTERLUDES.md    幕间「雪之间」定稿
docs/SCRIPT_SPEC.md   剧本语言规范      docs/HD_ART_SPEC.md 高清美术规范
tools/validate.js     剧本校验：node tools/validate.js
tools/autoplay.js     无头浏览器自动通关：node tools/autoplay.js prologue --all --thorough
tools/hd_preview.html 美术预览
```

开发者入口：`index.html?ch=ch3` 直接从某一章开始。结局路线测试：`--be be_ch1`（选择通往某个坏结局的选项）、
`--thorough`（结束搜查前把调查点再看一遍）、`--ft sayo,chiyuki`（自由时间优先选择）、`--bond chiyuki=4`、`--drop 证据id`。

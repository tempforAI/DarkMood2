# 幕间「雪之间」——定稿剧本（各章作者原样粘贴到本章文件末尾）

> 叙述性诡计：玩家应当以为「我」是 2003 年躲在炭烧小屋里的白蛾（甚至以为她就是还活着的冬木雪绘本人在复仇）。
> 真相：这是 **1983 年 2 月～4 月**、刚被送进雪里又被炭烧老人黑泽权藏救下的雪绘。
> **不要改动带【线索】注释的句子**（它们是公平线索）。不要给「我」写名字栏；老人用 `gonzo{老人}`。
> 每段以 `@goto` 回到本章的 `@chapterend` 之前的标签，或直接写在 `@chapterend` 之前。下面的标签名可按章节前缀改。
> 幕间里不出现「七濑」「侦探」「小夜」等 2003 年的人。不出现具体年份与日期字幕（`@caption` 只写「雪之间」）。

## 幕间一（序章末尾）

```
# prologue_interlude
@fade out
@bgm stop
@bg black
@wait 800
@title 雪之间|一
@bg charcoal_hut past
@filter dark
@weather none
@bgm lament
@fade in
@caption 雪之间
: ——炭的味道。
: 我先闻到的，是炭的味道。然后才是疼。手指、脚趾、脸颊，像有无数根针，一根一根往里钉。
: 我睁开眼睛。头顶是熏黑的椽子，一盏煤油灯，火苗缩得像一粒豆子。
: 我还活着。
: 这件事，花了我很久才弄明白。
gonzo{老人}: ……醒了？
: 一个老人蹲在灶边。他的脸被炉火照得一半红、一半黑，胡子上结着白霜。
gonzo{老人}: 别动。手上的布不能拆。拆了，指头就保不住了。
: 我想问他是谁。想问这是哪里。想问——那个孩子怎么样了。
: 我张开嘴。
: 喉咙里什么也没有。没有声音，连一点气音都没有。像是那场雪，把我的声音也一起埋掉了。
gonzo{老人}: 说不出话？……冻坏了，还是吓坏了，我也不懂。慢慢来。
: 他把一碗稀粥放在我手边。我的手被布缠成两团，捧不住碗。他就一勺一勺喂我。
: 粥很烫。我却一直在发抖。
@se wind
: 风从门缝里灌进来。门缝外面，是漆黑的山，和山脚下的村子。
: 村子里亮着灯。我一盏一盏地数。
// 【线索】三十二盏灯——2003 年的村子只剩十来户亮灯
: 三十二盏。
: 每一盏灯底下，都有一户人家。那天晚上，每一户人家，都投了票。
gonzo{老人}: 山神不收你。
: 老人往灶里添了一块炭，火光跳了一下。
gonzo{老人}: 山神不收的人，就得自己活下去。
: 我看着那三十二盏灯，看了很久，很久。
: 雪送，结束了吗？
: 还是说——
: 才刚刚开始。
@fade out
@weather none
@filter none
```

## 幕间二（第一章末尾）

```
# ch1_interlude
@fade out
@bgm stop
@bg black
@wait 600
@title 雪之间|二
@bg charcoal_hut past
@filter dark
@bgm lament
@fade in
@caption 雪之间
: 夜里，我总是梦见水车。
: 冻住的水车。黑黢黢的轮子上挂满了冰柱，像一排獠牙。
@flashback on
@bg watermill
@filter night
: 那天晚上，我推开水车小屋的门。
: 油灯倒在地上，还没有灭。灯光里，躺着一个男人。
: 还有一个女孩。
: 她跪在稻草上，两只手攥着一根铁杵，攥得指节发白。斗篷的红里子翻在外面，像一摊血。
: 她抬起头看我。十六岁的脸，白得像纸。
: 她的嘴唇在动，却发不出声音。——那时候我还不知道，没过几天，我也会变成那样。
: 我从她手里，把铁杵一根一根手指地掰下来，扔进稻草堆。
: 我对她说：
: 「你今晚没有来过这里。」
: 「回去。洗手，睡觉。什么都别说。」
: 「……什么都别说。」
: 她跑了出去。雪地上，她的脚印一路歪歪扭扭地通向山上的神社。
: 我在那里站了一会儿。男人的怀里，露出半截红色的东西——是我的发簪。那天晚上在旅馆，他从我头上扯下来的那一支。
: 我没有去拿。
: 我不知道为什么没有去拿。也许那一刻我已经想好了。也许，我只是太累了。
@flashback off
@bg charcoal_hut past
@filter dark
: 醒来的时候，天还没亮。
@se bell
// 【线索】召集村人的是火见橹的半钟——2003 年那口钟早已裂开、不再响
: 山下传来钟声。是火见橹上的半钟。三下，停一停，又是三下。
: ——那是召集全村的钟。
: 老人坐在门口，抽着烟，一动不动地听着。
gonzo{老人}: 又在敲了。
: 他没有说为什么。我也没有办法问。
: 我只是在心里一遍一遍地想：那个女孩，有没有洗手。有没有睡着。
: 有没有，什么都别说。
@fade out
@filter none
```

## 幕间三（第二章末尾）

```
# ch2_interlude
@fade out
@bgm stop
@bg black
@wait 600
@title 雪之间|三
@bg charcoal_hut past
@filter dark
@bgm lament
@fade in
@caption 雪之间
: 第七天，我第一次自己站了起来。
: 腿软得像煮烂的萝卜。我扶着墙走到门口，花了一整个上午。
: 老人在劈柴。他看见我，没有过来扶，只是把斧头放下，点了点头。
@se wind
: 门外是一片白。雪停了。从这里能望见整条山谷，和谷口那座桥。
// 【线索】吊桥是新的——2003 年它已锈迹斑斑（桥头铭牌：昭和五十七年竣工）
: 去年秋天才架好的吊桥，桥上的灯一盏一盏地亮着，像一串挂在山谷上的念珠。
: 村里人说，有了这座桥，冬天就不会再被困住了。
: 可是那天晚上，雪还是封住了路。
: 老人有一台很旧的收音机，用电池的。他每天晚上开一会儿，听天气。
// 【线索】东北新干线于 1982 年开通
: 收音机里沙沙地响：「……去年夏天开通的东北新干线，冬季运行至今……沿线降雪……」
: 他把收音机关了。说电池金贵。
: 我在灶边的木板上，用烧剩的炭条写字。指头不听使唤，写出来的字歪歪扭扭，像小孩子写的。
: 「为什么救我」
: 老人看了很久。
gonzo{老人}: 我也是被这个村子赶出来的人。
gonzo{老人}: 被赶出来的人，救一个被赶出来的人。就这么回事。
: 下午，风向变了。
// 【线索】分校里有孩子唱歌——分校 1991 年就停办了
: 风里飘来孩子们的歌声。是山脚下分校的孩子，在唱那首数雪的歌。
: 一片雪，落水车。二片雪，落屋檐……
: 我跟着在心里唱。唱到第六片雪，孩子们就不唱了。
: 第七片雪，从来没有歌词。
: 我给它填过词。在那个孩子睡不着的夜里，一句一句地，小声地唱给她听。
: 那个孩子，今年三岁。
@fade out
@filter none
```

## 幕间四（第三章末尾）

```
# ch3_interlude
@fade out
@bgm stop
@bg black
@wait 600
@title 雪之间|四
@bg charcoal_hut past
@filter dark
@bgm lament
@fade in
@caption 雪之间
: 左手的布，今天拆了。
: 无名指和小指，没有保住。老人用烧过的刀，把发黑的部分切掉了。我咬着一块木头，没有出声。
: 本来也出不了声。
gonzo{老人}: ……对不住。
: 他说这话的时候，没有看我。
: 晚上，他给了我一张包炭用的牛皮纸。我用剩下的三根手指捏着炭条，写了一封信。
: 写给我的女儿。
: 「千雪：
: 妈妈很好。妈妈没有做坏事。
: 等雪化了，等妈妈能说话了，妈妈就去接你。
: 要听外婆的话。要好好吃饭。睡不着的时候，就自己唱那首歌吧。第七片雪的那一段。」
: 写完，我把它折好，压在枕头底下。
: 我知道，这封信寄不出去。
: 一个「在暴风雪中逃亡失踪」的杀人嫌疑人，寄出去的信，只会把警察带到那个孩子身边。
: 只会让所有人知道——她的母亲还活着，而且是个杀人犯。
: 不如就让她以为，妈妈已经被山神带走了。
: 被山神带走的人，至少是干干净净的。
@se wind
: 半夜，我听见老人在门口咳嗽，咳了很久。
: 他的咳嗽声里，有一种我很熟悉的东西——我丈夫死前那一年，也是这样咳的。
: 我在黑暗里睁着眼睛。
: 这个世界上，救过我的人，好像都活不长。
@fade out
@filter none
```

## 幕间五（第四章末尾）

```
# ch4_interlude
@fade out
@bgm stop
@bg black
@wait 600
@title 雪之间|五
@bg valley
@filter dusk
@weather none
@bgm lament
@fade in
@caption 雪之间
: 四月。山谷里的雪开始化了。
: 积雪底下露出黑色的泥土，泥土里冒出一点一点的绿。
: 老人背着一个竹篓，走在我前面。我们走的是炭烧人运炭的小路，不经过村子，也不经过那座桥。
gonzo{老人}: 翻过这道梁，有条林道。运木头的卡车每周二下山。
gonzo{老人}: 到了镇上，你就是另一个人了。
: 我在一块石头上停下来，回头看。
: 村子就在下面。三十二户人家的屋顶上，雪化成了水，顺着屋檐一滴一滴地往下掉。
: 神社的石阶，白峰家的大屋，旅馆的烟囱。还有水车小屋——水车已经开始转了，吱呀，吱呀。
: 我在心里，对着那个村子说话。
: 我会回来的。
: 不是为了复仇。
: 是为了守着。
: 守着我丈夫的墓。守着那个女孩，看她能不能好好长大。守着这个村子，看它会不会再把谁送进雪里。
: 老人在前面等我。
gonzo{老人}: 你要是回来——
gonzo{老人}: 到那时候，我大概已经不在了。
: 我摇头。我想说「不会的」。
: 我张开嘴。
: 还是没有声音。
: 我只好在他手心里，用剩下的三根手指，写了两个字。
: 「谢谢」。
: 他看了很久，把手攥起来，像是攥住了什么会飞走的东西。
gonzo{老人}: ……走吧。
: 我们翻过了那道梁。
: 身后，村子里的半钟又响了。这一次，是正午的钟。
: 它敲得很慢，很慢，像是在数着什么。
@fade out
@filter none
```

## 终章：真相之后（2003 年，霜的第一人称）

终章在霜开口、千雪认出母亲之后，用 `@poem` 依次闪回幕间里的关键句，并**第一次显示年份**：

```
@poem 昭和五十八年（一九八三年）　二月十五日\n炭烧小屋\n\n「三十二盏。」
@poem 昭和五十八年　二月\n「去年秋天才架好的吊桥，桥上的灯一盏一盏地亮着。」
@poem 昭和五十八年　四月\n「我会回来的。不是为了复仇。是为了守着。」
```

然后（尾声前）写一段 2003 年霜的第一人称短独白（20～30 行，用 `:` 旁白，第一人称），主题：二十年的沉默，为什么回来，第一次用自己的声音叫女儿的名字。由终章作者完成，语气与上面五段一致。
